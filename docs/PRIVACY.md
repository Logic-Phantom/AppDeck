# 개인정보 처리 요약

| 데이터 | 언제 | 저장 위치 | 전송 |
|---|---|---|---|
| 설치 앱 목록(이름·아이콘·패키지·버전·설치/업데이트 시각) | Android, 온보딩 동의 후 | SQLite `apps`, 캐시 폴더 아이콘 PNG | 없음 |
| 사용자 데이터(분류·별칭·즐겨찾기·숨김·정리 후보) | 사용자가 편집할 때 | SQLite | 없음 |
| 앱덱 실행 기록(시각·성공/실패) | 앱덱에서 "열기"를 누를 때 (최근 100건) | SQLite `app_launch_history` | 없음 |
| 사용 기록 집계(최근 30일 마지막 사용 시각) | 선택 기능 ON + 시스템 권한 허용 + 정리 화면 진입 시 | 메모리만 (저장 안 함) | 없음 |
| 주차 메모(문구·사진·요금 규칙) | 사용자가 입력할 때 | SQLite, 앱 문서 폴더(사진 사본) | 없음 |

- 로그인, 서버, 광고 SDK, 분석 SDK, 원격 AI 없음.
- 앱 목록을 로그로 출력하지 않는다.
- 설정 > 앱 데이터 초기화: SQLite 전체 테이블 + 아이콘 캐시 삭제.
- 설정 > 데이터 내보내기: 민감 정보 경고 후 사용자가 직접 JSON을 공유.
