# Google Play 패키지 가시성 적격성 초안

상태: **정책 문서 조사 단계** (Play Console 사전 검토·실제 승인 전). 승인 가능성을 보장하지 않는다.

## 핵심 기능 설명 (Permissions Declaration Form 초안)
앱덱은 사용자가 휴대폰에 설치한 앱을 한곳에서 검색·카테고리별 분류·실행하는 개인용 앱 허브다.
"배달 주문", "길찾기"처럼 할 일을 입력하면 기기에 설치된 관련 앱만 모아 보여 주고 바로 실행한다.
설치 앱 목록 조회 없이는 핵심 기능(검색·분류·실행)을 제공할 수 없다.

## 왜 `<queries>`만으로 부족한가
사용자가 어떤 앱을 설치했는지 미리 알 수 없고, 특정 패키지 목록을 하드코딩하면 "설치 앱 전체 검색"이라는 목적을 달성할 수 없다.
단, 매니페스트에 `ACTION_MAIN/CATEGORY_LAUNCHER` `<queries>`도 함께 선언해 두었으므로 권한이 거부되면 해당 줄만 제거하고 런처 인텐트 범위로 fallback 한다.

## 데이터 처리
- 기기 안에서만 사용, 서버·광고·분석 전송 없음 (네트워크 SDK 없음)
- 첫 스캔 전 앱 내 고지 화면(온보딩) + 명시적 동의 버튼, 거부 시 수동 등록만 사용
- 설정에서 동의 철회 및 전체 삭제 가능
