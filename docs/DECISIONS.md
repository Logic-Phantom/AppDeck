# 설계 결정 기록 (ADR)

## ADR-001 Expo SDK 58 + Expo Router (`src/app`)
기존 구도픽·MoodMix와 동일 스택. 2026-11-24 기준 npm `expo@latest` = 58.0.26.

## ADR-002 Android 앱 목록은 Expo Modules API(Kotlin)
`modules/appdeck-device-apps`. `ACTION_MAIN + CATEGORY_LAUNCHER` 런처 앱만 조회하고, 아이콘은 캐시 폴더 PNG(`패키지_lastUpdateTime.png`)로 저장해 URI만 넘긴다. 사라진 패키지의 아이콘 캐시는 스캔 때 정리한다.

## ADR-003 `QUERY_ALL_PACKAGES` 선언 + `<queries>` 런처 인텐트 병행
앱의 핵심 목적이 "설치 앱 검색·분류·실행"이므로 선언한다. Play 심사에서 거부되면 매니페스트에서 이 줄만 제거해도 `<queries>` 범위(런처 인텐트)로 동작한다. 상세는 `PLAY_POLICY_ELIGIBILITY.md`.

## ADR-004 iOS는 수동 보관함만
일반 앱이 설치 앱 전체를 열거하는 공개 API가 없다. scheme 무작위 탐색·사설 API·Screen Time 우회는 하지 않는다. 수동 등록 앱은 `설치 여부 확인 불가`로 표시한다.

## ADR-005 사용 기록(UsageStats)은 선택 기능, 기본 OFF
사용자가 설명을 읽고 켠 뒤 시스템 설정에서 직접 허용해야 한다. 정리 화면을 열 때만 30일 집계를 조회하고 저장하지 않는다. `lastTimeUsed`가 없으면 "정보 없음".

## ADR-006 레퍼런스 디자인 대비 내용 조정 (레이아웃은 유지)
제품 원칙(가짜 데이터·광고 금지)과 충돌하는 문구만 바꿨다.

| 레퍼런스 | 구현 | 이유 |
|---|---|---|
| 검색 결과 하단 "지금 배달하면 최대 5천원 할인!" 배너 | 같은 위치·모양의 카드: "찾는 앱이 없나요? 직접 등록해 두세요" / 길찾기는 "주차 위치 기록" | 광고·추측성 할인 정보 금지 |
| 앱 정리 "사용 중인 앱 72개", "이번 주에 사용하지 않은 앱 3개" | "관리 중인 앱 N개", "정리 후보로 표시한 앱 N개" (사용 기록 허용 시 "최근 30일 실행 기록 없음") | 사용 기록 없이 미사용을 추정하지 않음 |
| "선택 삭제" | "선택 정리" → 앱덱에서 숨기기 / 앱 정보 열기 / 후보에서 빼기 | 타 앱 자동 삭제 금지, `REQUEST_DELETE_PACKAGES` 미사용 |
| "이제 더 가볍고 빠르게 앱을 사용할 수 있어요" | "이제 필요한 앱을 더 빠르게 찾을 수 있어요" | 성능 개선을 주장하지 않음 |
| 설정 "알림 설정" | "앱 목록 설정" | 알림 기능이 없어 가짜 토글을 만들지 않음 |
| 즐겨찾기 "최근 사용한 앱" | 동일 제목 + "앱덱에서 실행한 기록만" 안내 | 기기 전체 사용 기록으로 오해 방지 |
| 앱 아이콘(배민·넷플릭스 등 로고) | 실기기: OS가 준 원본 아이콘 / 웹 데모: 이름 모노그램 | 타사 상표 이미지 복제 금지 |

## ADR-007 레퍼런스에서 아이콘 추출
홈의 목적 아이콘 6종과 반짝이 아이콘은 `scripts/extract-reference-icons.mjs`로 레퍼런스 이미지에서 잘라 배경을 투명 처리해 사용한다. 라인 아이콘(탭바·설정 등)과 정리 완료 일러스트는 원본 해상도가 낮아 SVG로 재현했다.

## ADR-011 디자인 레퍼런스 v2 적용 (2026-11-25)
`assets/reference/appdeck-design-reference-v2.webp`를 새 기준으로 삼는다(v1은 기록용으로 보관).
레이아웃·문구는 그대로 따르되 제품 원칙과 충돌하는 부분만 조정했다.

| 레퍼런스 v2 | 구현 | 이유 |
|---|---|---|
| 앱 정리 "최근 30일간 사용하지 않은 앱 3개를 지울 수 있어요" | 사용 기록을 허용한 경우에만 이 문구, 아니면 "정리 후보로 표시한 앱 N개를 정리할 수 있어요" | 사용 기록 없이 미사용 추정 금지 |
| 보관함 "앱 정리 팁: 최근 30일간 사용하지 않은 앱이 3개" | 위와 같은 규칙 | 동일 |
| 설정 "알림 설정" | OS의 앱 설정 화면을 연다 | 앱덱은 알림을 보내지 않음, 가짜 토글 금지 |
| 설정 "고객센터" | GitHub 이슈 페이지 링크 | 별도 지원 채널 없음 |
| 앱 버전 v1.0.0 | 실제 버전(v0.1.0) 표시 | 사실과 다른 버전 표기 금지 |
| 보관함 "최근 사용" | 앱덱에서 실행한 기록만 | 기기 전체 사용 기록으로 오해 방지 |
| 타사 앱 로고 | 실기기: OS 원본 아이콘 / 웹 데모: 모노그램 | 상표 이미지 복제 금지 |

## ADR-012 카테고리 v2 (20개, 그룹 4개)
그룹: 라이프스타일 / 엔터테인먼트 / 이동·여행 / 소통·도구. 기존 저장 데이터 호환을 위해 `system_tools` id는 유지하고 이름만 "유틸리티"로 바꿨다.
교통(시내 이동: 택시·지하철·시내버스·주차·킥보드)과 여행(기차·고속/시외버스·항공·숙박)을 분리했다. 같은 패키지가 여러 규칙에 맞으면 가장 긴 패턴이 이긴다(예: `tmoneybus` → 여행, `tmoney` → 교통).
레퍼런스에 3D 아이콘이 없는 14개 카테고리는 같은 톤의 광택 SVG(`src/design-system/CategoryIcon.tsx`)로 그렸다.

## ADR-009 Android 빌드는 EAS 클라우드 (Windows 로컬은 보조)
작업 PC 경로에 한글이 있고 Windows 긴 경로 지원이 꺼져 있어 로컬 Gradle/CMake 빌드가 실패한다.
`eas build -p android --profile preview` (APK, EAS 관리 서명 키)를 기본 경로로 쓴다.
로컬 빌드가 필요하면 ASCII 짧은 경로(예: `C:\ad`)에 복제하고 Windows `LongPathsEnabled=1`을 켠 뒤 `scripts/android-build.ps1`을 사용한다.

## ADR-010 react-native-gesture-handler 자동 링크 제외
앱덱은 제스처 핸들러를 쓰지 않는다(전이 의존성). 네이티브 코드량과 경로 길이 문제를 줄이려고 구도픽과 같이 `expo.autolinking.exclude`로 제외했다.

## ADR-008 주차 위치 메모
레퍼런스의 "주차 위치" 화면을 위치 권한 없이 구현: 사용자가 입력한 층/구역 문구, 시스템 사진 선택기로 고른 사진, 직접 입력한 요금 규칙만 저장한다.
